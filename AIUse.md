# AI-Use Statement

I mainly used ChatGPT and Codex for idea generation and finding gaps in where
Mathlib didn't have any formalizations. For example, after attending office 
hours with the TAs, they suggested I ask LLMs to run through Mathlib and find
what combinatorial identities are not really worked on in Mathlib, which guided
me to work with Rencontres numbers. 

Most of my AI use is stated within the code with comments whenever I needed to 
find the correct Mathlib identity to rewrite or simplify with. Also setting up
some proof statements at the beginning of Rencontres section with the right 
notation was guided with Codex (ex. the set up for hcondition in the theorem
derangement_on_fixed_set_count). A lot of explanation of the code I was writing
was also given to sometimes help me improve upon the style or simplification.
